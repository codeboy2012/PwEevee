<h1 align="center">PwEevee</h1>

<p align="center">
  <strong>One Spotify build. Two upstreams. A lot of PwEevee on top.</strong><br>
  Chroma + EeveeSpotify, packaged into a single sideloadable IPA.
</p>

PwEevee is an open-source Spotify customization project. It brings
[Chroma](https://chroma.pw/) (formerly Spoti.pw) and EeveeSpotify together in one
IPA, then adds PwEevee's own icon picker, settings, diagnostics and packaging work.

**v3.1.6.1 is the current release.** v4 is being rebuilt from the ground up.

## v4 is the biggest change yet

v4 is not a reskin or a bundle update. It is a ground-up rebuild of PwEevee's
foundation, experience and website.

The goal stays the same: one Spotify build that brings the best of Chroma and
EeveeSpotify together, with PwEevee's own ideas layered on top. How that feels, how it
is put together, and how much of it is genuinely PwEevee is what changes.

### What's coming

- **Original PwEevee features.** v4 moves beyond integration work and adds ideas that
  do not exist in either upstream project.
- **More customization.** A deeper icon and appearance system, with more ways to make
  Spotify feel like yours.
- **A clearer experience.** Settings, onboarding and diagnostics rebuilt around fewer
  dead ends and plainer language.
- **Integrations that keep up.** Chroma and EeveeSpotify stay distinct projects;
  PwEevee keeps them working together as they evolve.
- **A new website and documentation.** Both are being rebuilt from scratch for v4. The
  old v3 site and its automation will not be restored.

### Sneak peeks

These are directions, not shipped features. Nothing below is in v3.1.6.1, and the
details will change.

| Direction | What we're aiming for |
|---|---|
| One settings surface | Less hunting through separate mod panels. Clearer grouping, clearer words, fewer surprises. |
| A bigger icon system | More ways to match your home screen, with the picker doing more of the work. |
| Upstream, without the guesswork | Clearer compatibility information for Chroma and EeveeSpotify, so you know what works before you install. |
| PwEevee-original ideas | Features that belong to neither upstream. Some are still on the whiteboard. |

### Where this is going

The long-term direction is a PwEevee that is more than a package of upstream tweaks: a
coherent Spotify customization layer with its own identity, its own features and a much
better first-run experience.

The work is organized in phases, not dates. See [ROADMAP.md](ROADMAP.md) for the plan.

## Development status

v4 is in early development. There is no release date, no public beta and no
feature-complete build. The roadmap describes phases, not a schedule. When there is
something to test, it will be announced on GitHub Releases.
