Install guide

Download, verify, sign, install.

PwEevee ships as an unsigned IPA published through its own GitHub release. The three steps below — download the release, verify its SHA-256, sign it with your own certificate — are the same for every signing tool, because the file is the same file. Nothing is claimed as installed-and-tested unless it was tested; compatibility notes on this page are labelled by where they came from.

Step 1 · Download

Get the release file from GitHub.

The current release, its file size and its checksum are read straight from the GitHub release the file is published in. If the release data cannot be read right now, the download and the checksum are hidden rather than guessed.

Release history and previous builds: the release history page and the upstream GitHub releases list. The notes on the release panel above are the release’s own.

Step 2 · Verify

Check the SHA-256 before you sign.

The site shows the checksum that GitHub publishes with the release asset (full value on the panel above, first 16 characters on asset lists). Compute the file’s checksum locally and compare — if they differ, you do not have the release file.

How to compute it

  • macOS / Linux — shasum -a 256 FILE.ipa
  • Windows (PowerShell) — Get-FileHash -Algorithm SHA256 FILE.ipa
  • Windows (cmd) — certutil -hashfile FILE.ipa SHA256

Compare against the value shown on this page or on the GitHub release itself. Both are read from the same release data; nothing here invents a checksum.

Why it matters

It confirms the file you downloaded is the file the release published — a real integrity check, not proof the build is safe to run against Apple’s policies. You are still side-loading Spotify software that the App Store does not distribute; treat any third-party IPA with the usual caution and use your own signing identity.

Step 3 · Sign & install

Sign with your own certificate.

Pick one tool and follow its docs for signing an existing IPA. These tools are third-party applications with their own requirements (accounts, certificates, refresh scheduling); their installation steps live in their documentation, and PwEevee does not mirror or certify any of them.

AltStore Classic

Uses your Apple ID’s free-provisioning certificate. Installs from a computer running the AltServer companion; on a free Apple account apps are limited to three and must be refreshed inside 7 days.

Source: altstore.io

SideStore

AltStore-style sideloading that can refresh on-device. Import the signed IPA into the SideStore app to install it, or install over the network from the paired computer by opting in.

Source: sidestore.io

Other known-good signers

  • Feather — on-device signing and install
  • Sideloadly — computer-based signing with a free or paid certificate
  • AltStore on-device — same app, installed copy of AltServer, no Mac required

Any signer that accepts a plain IPA works; what changes between tools is how the certificate is obtained and kept alive.

The app inside a PwEevee IPA is Spotify; the spoti.pw and EeveeSpotify tweaks are already inside the build — there is nothing else to install afterwards. Logo and Apple-ID DataStream setup belong in the signing tool you choose.

Installing from the SideloadLabs AltSource

AltStore and SideStore can also talk to an installed AltStore-format source: a JSON manifest that lists ready-made IPA variants so the app can fetch them in-app. These independent builds are published by SideloadLabs, not by PwEevee; PwEevee reads that manifest and links it, and does not mirror it.

[[component:altsource-source eeveespotify]]

Add the source in your installer

In AltStore or SideStore open Sources → + and paste the manifest URL shown on this panel. Each listed variant names its upstream Spotify version, its Eevee version and which certificate the build suits.

  • Unpatched — for use with a free certificate in AltStore or SideStore
  • Patched — for a paid certificate, a jailbreak, or TrollStore
  • ESR Liquid Glass — the same tweak with the Liquid Glass interface

The current URL is read live from the manifest, so what you see here is the URL you should paste. If the panel above says the source is unavailable, install with a manual IPA from the downloads page instead.

What to try, in order

Troubleshooting.

The installer refuses the IPA

  • verify the SHA-256 first — a truncated download is the most common cause
  • your free Apple account already signs three apps (free-provisioning limit)
  • the IPA targets a newer Spotify than your certificate or the signer allows

Install works, app then crashes or the tweak is missing

  • check whether the signer ships its injection mechanism needed by the tweaked build
  • re-sign freshly: reusing a stale provisioning profile is a known source of launch crashes
  • report it on GitHub issues with your exact iOS version, signing tool and PwEevee version

Known limits are stated, not papered over: PwEevee builds are unsigned and no physical-device install is tested by this site’s maintainer in every environment. Where a compatibility claim has not been verified, this site says so on the project page rather than claiming success.

Platform check. PwEevee is currently available for iOS only. Android is not supported at this time: no Android build exists, no Android download is offered anywhere on this site, and this notice would appear again anywhere the site detects an Android device. You can follow the project on GitHub for future announcements.

Browsing from Windows, macOS, or Linux? Those are platforms this website supports, not platforms PwEevee runs on — there is no desktop build, only the browser pages you are reading now.
