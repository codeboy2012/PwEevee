Before you install. PwEevee builds are unsigned — sign them with your own certificate (SideStore, Feather, AltStore, Sideloadly, …). The full walk-through — checksum verification, AltStore Classic, SideStore and troubleshooting — is on the install guide.

EeveeSpotify IPA variants

SideloadLabs publishes ready-to-install IPAs in an AltStore-format source. Each build comes in a Standard and a Patched variant — pick by how you sign apps, not by version. Every fact below, including the download URL, is read from that source.

Standard or Patched?

  • Standard — unpatched, intended for a free certificate in AltStore or SideStore
  • Patched — intended for a paid certificate, a jailbreak or TrollStore
  • Liquid Glass — the same tweak with the Liquid Glass interface

These variants come from SideloadLabs, not from PwEevee, and they are a different thing from the EeveeSpotify GitHub release shown below. Install questions belong with the publisher.

How to verify a download

  1. copy the SHA-256 shown on the release you downloaded, where the publisher provided one
  2. hash your file locally — shasum -a 256 <file>.ipa on macOS or Linux, Get-FileHash <file>.ipa in PowerShell
  3. compare the two values; they must match exactly, character for character
  4. if they differ, do not install the file — re-download it and check again
