What this is

An integration project, stated plainly.

What PwEevee does

  • obtains and prepares compatible upstream components
  • integrates them and resolves their dependencies against each other
  • builds the combined app and installs every component's resources
  • validates each build end to end, and a failed check stops the release
  • packages one installable IPA and publishes it as a GitHub release
  • runs this website, which reads those releases rather than repeating them

What PwEevee does not do

  • claim ownership of the upstream projects
  • claim authorship of any upstream tweak
  • claim affiliation with Spotify, Apple, spoti.pw or EeveeSpotify
  • sell or re-license anyone else's software
  • claim any right to Spotify itself, which remains Spotify AB's software

How it works

Five steps, start to finish.

PwEevee builds and publishes the finished app. Your side is downloading it, signing it with whatever method you already use, and installing it.

  1. Choose a build. The downloads page lists what is published, with its version, size and checksum read straight from the release.
  2. Download the IPA. One file. The download button only appears when the file behind it actually exists.
  3. Sign it. PwEevee builds are unsigned, so sign with your own certificate using SideStore, AltStore, Feather, Sideloadly or an equivalent — or run the browser workshop to validate a certificate and a provisioning profile against a downloaded IPA before you commit to signing it.
  4. Install it. Your signing tool sideloads the signed IPA onto the device.
  5. Open it and use it. The tweaks are already inside the build — there is nothing else to add afterwards.

Building PwEevee from source instead? That path, and the validation the build has to pass, is documented on the PwEevee project page.

Release notes from the author

PwEevee 3.1.0 — Major Feature Release

PwEevee 3.1.0 is a major feature release focused on performance, customization, lyrics, lock-screen improvements, audio features, and downloads. Built around Spotify 9.1.90, this release brings together requested features, improvements from the Vitrine project, and Pixie Download Manager's native Spotify offline-download functionality.

Downloads

  • PwEevee 3.1.0 — PwEevee-3.1.0.ipa (140.23 MB)

The PwEevee release IPA with the integrated features and customizations.

  • Clean Decrypted Spotify 9.1.90 — com.spotify.client_9.1.90_und3fined.ipa (146.37 MB)

The clean, decrypted Spotify 9.1.90 IPA used as the base for PwEevee. It is decrypted but otherwise unmodified and does not include EeveeSpotify or other tweaks. It is provided separately for users who need the clean IPA for compatible tools such as Chroma.

What's New

Performance and Quality of Life

  • Improved performance and responsiveness.
  • Faster interactions and loading.
  • Performance optimizations intended to reduce battery usage.
  • General stability improvements and bug fixes.
  • More requested features and quality-of-life settings.
  • An option to disable automatic UI hiding.
  • More ways to customize the app's navigation and appearance.

Native Downloads — Pixie Download Manager

PwEevee integrates Pixie Download Manager v1.3, built on the Vitrine project and targeting Spotify 9.1.90.

  • Native Spotify offline downloads for tracks, albums, and playlists.
  • Download the album associated with the currently playing track directly from the manager.
  • Redesigned download controls and album actions.
  • Improved playlist and mix headers where Spotify provides both Add and Download controls.
  • Download status and related diagnostics available through Vitrine settings.
  • Offline-device management, including identifying the current registration and removing entries.
  • Optional diagnostics, with a single action to export JSON diagnostic logs.
  • English interface.

Downloads are stored in Spotify's offline storage for playback within Spotify. Exporting ordinary MP3, M4A, or OGG files is not implemented.

Download performance: The reported estimate is approximately 45–75 MB for around 100 songs, depending on the content and download conditions. Actual storage use can vary.

The native download integration is based on https://github.com/Glongq/Vitrine-Pixie" rel="noopener nofollow ugc" target="_blank">[Glongq/Vitrine-Pixie. Its published IPA download and update information are available through the https://t.me/glongqforks/5" rel="noopener nofollow ugc" target="_blank">[project's Telegram post. The repository contains source code and patches rather than hosted IPA files.

Lyrics

  • Word-by-word lyrics highlighting, with surrounding lines visually softened.
  • Tap a lyric line to jump to that point in the song.
  • Line-by-line translations.
  • Lyrics translations into other languages when supported.
  • Genius annotations for selected lyric lines.
  • Improved Arabic and Hebrew text direction.
  • Dedicated landscape lyrics layout, designed specifically for landscape rather than stretching the portrait interface.
  • Return to portrait mode without losing your place in the player.
  • Improved lock-screen lyrics presentation.

Landscape Lyrics

  • A dedicated full-screen landscape lyrics experience.
  • Larger lyrics spanning the screen width.
  • Controls that appear when touched.
  • A layout designed specifically for landscape use.
  • Returning to portrait restores the player experience.

Sing and Vocal Controls

  • Adjust vocal volume from full volume down to silent, where supported.
  • Sing along with lyrics that remain synchronized with playback.
  • With compatible AirPods and supported spatial-audio functionality, vocals can remain positioned in front of the listener as they turn their head.

Availability depends on device hardware, audio configuration, and feature support.

Lock Screen Customization

  • Lyrics displayed on the lock screen, with the current line updating during playback.
  • Multiple lock-screen presentation styles.
  • Animated cover support where available.
  • More customization for the lock-screen artwork.

Additional styles may be possible through compatible customization tools, but unintegrated Workshop themes are not included in this release.

Animated Album Artwork

  • Animated album covers in the player and on album pages where supported.
  • Improved presentation for animated artwork.
  • Live Activity controls and information, where supported, including playback controls, queue information, or a sleep timer.
  • Like and dislike actions from supported lock-screen controls.

Artist Pages

  • Improved artist-page presentation with prominent artwork and artist names.
  • Easier access to liked songs from an artist.
  • A more cohesive visual experience across supported artist pages.

The ecosystem

Three projects, clearly separated.

PwEevee is maintained here. spoti.pw and EeveeSpotify are separate upstream projects with their own authors, repositories and licenses. Versions and dates come straight from each project's GitHub releases.

PwEevee

Maintained here

One tested Spotify IPA carrying two upstream tweaks.

PwEevee is the integration layer: it obtains and prepares compatible upstream components, resolves their dependencies (duplicates fail the build), injects the tweaks into a decrypted Spotify binary, validates Mach-O load commands and filesystem structure, packages a reproducible IPA with a full build manifest, and publishes the result through GitHub releases with its exact SHA-256.

Project status

PwEevee is maintained by a single developer in available free time. There is no guaranteed release schedule; new builds may take longer when life gets in the way. If this maintainer stops, someone else may be able to continue from the available source and the applicable upstream licenses and rights — preserving licenses, copyright notices and attribution. That is a statement about continuity, not a claim of unrestricted redistribution rights.
