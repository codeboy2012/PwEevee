What this is

An integration project, stated plainly.

What PwEevee does

  • obtains and prepares compatible upstream components
  • integrates them and resolves their dependencies against each other
  • builds the combined app and installs every component's resources
  • validates each build end to end, and a failed check stops the release
  • packages one installable IPA and publishes it as a GitHub release
  • runs this website, which reads those releases rather than repeating them

What PwEevee does not do

  • claim ownership of the upstream projects
  • claim authorship of any upstream tweak
  • claim affiliation with Spotify, Apple, spoti.pw or EeveeSpotify
  • sell or re-license anyone else's software
  • claim any right to Spotify itself, which remains Spotify AB's software

How it works

Five steps, start to finish.

PwEevee builds and publishes the finished app. Your side is downloading it, signing it with whatever method you already use, and installing it.

  1. Choose a build. The downloads page lists what is published, with its version, size and checksum read straight from the release.
  2. Download the IPA. One file. The download button only appears when the file behind it actually exists.
  3. Sign it. PwEevee builds are unsigned, so sign with your own certificate using SideStore, AltStore, Feather, Sideloadly or an equivalent — or run the browser workshop to validate a certificate and a provisioning profile against a downloaded IPA before you commit to signing it.
  4. Install it. Your signing tool sideloads the signed IPA onto the device.
  5. Open it and use it. The tweaks are already inside the build — there is nothing else to add afterwards.

Building PwEevee from source instead? That path, and the validation the build has to pass, is documented on the PwEevee project page.

Release notes from the author

PwEevee v2.0.0

> Major Release — EeveeSpotify 7.0.0

PwEevee v2.0.0 is a major update that brings the project to the new EeveeSpotify 7.0.0 generation, with a large number of new features, a redesigned experience, Liquid Glass support, Spotify version spoofing, and many stability and UI improvements.

This release is a major overhaul from the previous v1.x builds.

⭐ Recommended Build

EeveeSpotifyv7.0.0.ipa

154 MB — 161,793,103 bytes

This is the recommended PwEevee build.

It provides the new EeveeSpotify 7.0.0 experience while avoiding the additional restrictions introduced by the newer SpoTi.pw releases.

Highlights

  • EeveeSpotify 7.0.0
  • Liquid Glass support
  • Redesigned settings experience
  • Updated customization system
  • Enhanced lyrics and karaoke features
  • Custom lyrics improvements
  • Tab customization
  • Appearance customization
  • Player customization
  • App flag tool
  • Privacy and stability improvements
  • Updated iOS 26/27 experience
  • Major underlying updates from previous versions

This is the build we recommend for most users.

Optional Combined Build

SpoTiv50.0.0+EeveeSpotifyv7.0.0.ipa

133 MB — 139,507,438 bytes

This build combines:

  • SpoTi.pw 0.50.0
  • EeveeSpotify 7.0.0

It provides a larger portion of the functionality available through the SpoTi.pw + EeveeSpotify combination.

However, this build is optional and is not our primary recommendation.

The newer SpoTi.pw releases have introduced paid/premium functionality, so users looking for the best free experience should generally use the EeveeSpotify 7.0.0 build instead.

> Important: The combined build does not contain every feature from SpoTi.pw 0.50.0.

Why EeveeSpotify Is Recommended

PwEevee's goal is to provide a powerful Spotify customization experience without requiring users to rely on paid functionality.

The standalone EeveeSpotify 7.0.0 build already provides a substantial feature set, including:

  • Liquid Glass
  • Spotify version spoofing
  • Advanced appearance customization
  • Tab customization
  • Custom lyrics
  • Karaoke / lyrics enhancements
  • Player customization
  • Remote feature flags
  • Extensive settings customization
  • Privacy and stability improvements

For most users, EeveeSpotify 7.0.0 is the build to install.

What's New in v2.0.0

This release represents a major evolution of PwEevee.

The project has moved from the older v1.x integration toward the significantly newer EeveeSpotify 7.0.0 codebase, bringing a redesigned interface, Liquid Glass support, Spotify version spoofing, expanded customization, improved lyrics functionality, remote configuration capabilities, and numerous stability improvements.

The ecosystem

Three projects, clearly separated.

PwEevee is maintained here. spoti.pw and EeveeSpotify are separate upstream projects with their own authors, repositories and licenses. Versions and dates come straight from each project's GitHub releases.

PwEevee

Maintained here

One tested Spotify IPA carrying two upstream tweaks.

PwEevee is the integration layer: it obtains and prepares compatible upstream components, resolves their dependencies (duplicates fail the build), injects the tweaks into a decrypted Spotify binary, validates Mach-O load commands and filesystem structure, packages a reproducible IPA with a full build manifest, and publishes the result through GitHub releases with its exact SHA-256.

Project status

PwEevee is maintained by a single developer in available free time. There is no guaranteed release schedule; new builds may take longer when life gets in the way. If this maintainer stops, someone else may be able to continue from the available source and the applicable upstream licenses and rights — preserving licenses, copyright notices and attribution. That is a statement about continuity, not a claim of unrestricted redistribution rights.
