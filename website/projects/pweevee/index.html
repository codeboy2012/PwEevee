PwEevee

One tested Spotify IPA carrying two upstream tweaks. PwEevee is the integration layer: it obtains and prepares compatible upstream components, resolves their dependencies (duplicates fail the build), injects the tweaks into a decrypted Spotify binary, validates Mach-O load commands and filesystem structure, packages a reproducible IPA with a full build manifest, and publishes the result through GitHub releases with its exact SHA-256.

PwEevee v2.0.0

> Major Release — EeveeSpotify 7.0.0

PwEevee v2.0.0 is a major update that brings the project to the new EeveeSpotify 7.0.0 generation, with a large number of new features, a redesigned experience, Liquid Glass support, Spotify version spoofing, and many stability and UI improvements.

This release is a major overhaul from the previous v1.x builds.

⭐ Recommended Build

EeveeSpotifyv7.0.0.ipa

154 MB — 161,793,103 bytes

This is the recommended PwEevee build.

It provides the new EeveeSpotify 7.0.0 experience while avoiding the additional restrictions introduced by the newer SpoTi.pw releases.

Highlights

  • EeveeSpotify 7.0.0
  • Liquid Glass support
  • Redesigned settings experience
  • Updated customization system
  • Enhanced lyrics and karaoke features
  • Custom lyrics improvements
  • Tab customization

  • App flag tool
  • Privacy and stability improvements
  • Updated iOS 26/27 experience
  • Major underlying updates from previous versions

This is the build we recommend for most users.

Optional Combined Build

SpoTiv50.0.0+EeveeSpotifyv7.0.0.ipa

133 MB — 139,507,438 bytes

This build combines:

  • SpoTi.pw 0.50.0
  • EeveeSpotify 7.0.0

It provides a larger portion of the functionality available through the SpoTi.pw + EeveeSpotify combination.

However, this build is optional and is not our primary recommendation.

The newer SpoTi.pw releases have introduced paid/premium functionality, so users looking for the best free experience should generally use the EeveeSpotify 7.0.0 build instead.

> Important: The combined build does not contain every feature from SpoTi.pw 0.50.0.

Why EeveeSpotify Is Recommended

PwEevee's goal is to provide a powerful Spotify customization experience without requiring users to rely on paid functionality.

The standalone EeveeSpotify 7.0.0 build already provides a substantial feature set, including:

  • Liquid Glass
  • Spotify version spoofing
  • Advanced appearance customization
  • Tab customization
  • Custom lyrics
  • Karaoke / lyrics enhancements
  • Player customization
  • Remote feature flags
  • Extensive settings customization
  • Privacy and stability improvements

For most users, EeveeSpotify 7.0.0 is the build to install.

What it is

The glue, and only the glue.

PwEevee did not create the software it distributes. Its contribution is integration engineering: making two independently developed tweaks coexist inside one app, proving the result is structurally sound, and publishing it with a manifest that says exactly what went in.

Build system

  • one authoritative pipeline — no manual editing between steps
  • dependency resolver where duplicate dependencies are a hard failure
  • Mach-O load-command injection, audited byte-for-byte against a proven reference build
  • Mach-O, dependency, filesystem and package-format validation
  • deterministic store-only IPA packaging

The eight stages

Every published build took this path. Any failing stage stops the build; validations are never weakened to make something ship.

  1. read the decrypted Spotify app that the build takes as its input
  2. prepare and merge the spoti.pw + EeveeSpotify payloads
  3. resolve dependencies — duplicates are a hard failure
  4. inject Mach-O load commands
  5. validate the Mach-O binary and every declared dependency
  6. validate the filesystem structure and resources
  7. package a deterministic IPA and compute its SHA-256
  8. publish the build manifest and the IPA as a GitHub release

Release infrastructure

  • every build ships a manifest with component versions and SHA-256
  • builds published as GitHub releases — the release is the download
  • a download button is only rendered when the release asset really exists
  • release data for the whole ecosystem generated from the GitHub API
  • this site rendered statically — it works with JavaScript disabled

Build it yourself

One command, on plain tooling.

For anyone who would rather reproduce a build than download one. Requirements are bash, perl with core modules only, xz and unzip — no Theos, no Xcode, no macOS. This is the same workflow PwEevee's own builds go through, and it takes a decrypted Spotify app as its build input. Installing a published PwEevee release needs none of this.

From the repository root:

bash PwEvevee/build-system/unified.sh <decrypted-spotify.ipa> -o dist/my-build.ipa

That single command runs merge → resolve → inject → validate → package → manifest → tests and stops with a named error if anything is wrong. Full detail lives in docs/BUILD.md in the repository.
