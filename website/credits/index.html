Bundled runtime dependencies

  • Orion — tweak injection runtime by theos, as shipped inside the upstream EeveeSpotify deb
  • EeveeSwiftProtobuf — Swift protobuf library as shipped in that package
  • CydiaSubstrate — Saurik's Substrate framework, binary and Info.plist as shipped in the proven spoti.pw build
  • Spotify — the app itself is Spotify AB's software, neither created nor owned by this project; PwEevee's work is the integration and build workflow around it

Tooling the build stands on

  • Theos — theos.dev — builds the spoti.pw tweak
  • cyan (pyzule-rw) — upstream spoti.pw's injector, used in its pipeline
  • libbs2b (MIT) and WDL/EEL2 (zlib) — audio-effects code vendored by spoti.pw, licenses preserved
  • FLEX / AutoFLEX — debug inspector used by spoti.pw's harness

This project

What PwEevee actually contributed

PwEevee did not create any of the above. Its contribution is integration, build, packaging, testing, hosting and distribution:

  1. one unified build pipeline and dependency resolver — duplicates fail the build
  2. Mach-O load-command injection and the validation suite around it
  3. byte-exact Debian packaging generator with automated format tests
  4. deterministic IPA packager and build manifests
  5. this website, its documentation, and the GitHub release automation behind it

Maintained by one developer. See Development for how the work is done.
