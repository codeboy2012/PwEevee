# Downloads

Spotify 9.1.90's own offline downloads, unlocked, and the page in Mod Settings that drives them.

This directory is the **Pixie Download Manager** engine by [Glongq](https://github.com/Glongq/Vitrine-Pixie)
(v1.2, source pinned to Spotify 9.1.90), taken from Vitrine-Pixie and trimmed for PwEevee. It is licensed
GPL-3.0 (`LICENSE-Pixie-GPL-3.0`); its notices stay as they are.

    src/      the companion library, built into SpotifyAudioProbe.dylib and injected beside the tweak
    tools/    build_downloads.py (run by scripts/pipeline.sh) and the three guarded patchers it uses

## What happens at build time

`scripts/pipeline.sh` runs `tools/build_downloads.py` on the decrypted IPA before the tweak is injected:

1. It checks the Spotify version and the executable's UUID. Anything but 9.1.90 / `fbce22c1…943e` exits 3 and
   the build goes on **without** Downloads; the Downloads page then says so.
2. `patch_native_restrictions.py` clamps the offline limits Spotify's server sends, `patch_key_request_mode.py`
   fixes the offline key request to mode 0, `patch_native_trace.py` adds passive observation points. Each one
   compares the exact original bytes first and writes only into zero-filled `__TEXT` header padding.
3. The companion library is compiled and handed to `cyan` with the tweak.

Pass `--no-downloads` to `pipeline.sh` to skip all of it.

The pipeline verifies Downloads in the finished IPA whenever it includes them. To check an existing IPA,
run `python3 extension/Downloads/tools/verify_downloads.py path/to/PwEevee.ipa`. It verifies the companion
and its load command, and compares all guarded patch entries and trampolines against the expected bytes.
Run local configuration and packaging regression checks with
`bash harness/downloads/build.sh` and `python3 -m unittest discover -s harness/downloads -p 'test_*.py'`.

## What changed from Vitrine-Pixie

- The settings screens are gone; PwEevee draws its own in `tweak/Sources/Shared/Downloads/`. The tweak never
  links this library: it finds `SAPPwEeveeBridge` (`src/PwEeveeBridge.m`) by name at runtime.
- The AudioToolbox import redirect, the AVFoundation hooks and the WAV capture are gone. PwEevee's
  `Shared/Audio/SGAudioPipeline.x` rebinds the same imports, and downloading never used them. `ProbeStubs.*`
  answers what the diagnostics still read. The "Audio diagnostics" page went with them.
- Jailbreak (DEB) support is not included.

## Keeping it in sync

The `*Patch.h` / `OfflineLimits.h` headers in `src/` are generated by the patch tools and `build_downloads.py`
refuses to build when they differ. After touching a patch tool, regenerate them the way Vitrine-Pixie's
`BUILD.md` describes.
