# Temporary PwEevee landing page

This directory is the small placeholder for the PwEevee website while the v4 site is
being rebuilt. It is not the v4 website and it does not restore the retired v3 site.

- `index.html` is the whole page.
- `icon.png` is the app icon used by the page and its favicon.
- There is no build step and no package install. Copy this directory to the website
  docroot, or serve it with any static file server.

The page links downloads and release information to
[GitHub Releases](https://github.com/codeboy2012/PwEevee/releases) and links Chroma to
[chroma.pw](https://chroma.pw/).
