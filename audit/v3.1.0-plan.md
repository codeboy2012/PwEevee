## v3.1.0 acceptance criteria (measurable)

1. All test suites pass in CI (the environmental skip stays green by design, not masked).
2. Released unified IPA's main binary passes `validate-macho.pl` (strong expected set; weak set validated after P2-2).
3. Release + website manifest list per-component sha256; the substrate row equals the repo pin.
4. Every component manifest is verified by `component-manifest-test.pl` in CI.
5. No package ships where a released bundle's pin ≠ repo pin without an explicit provenance note in the release card.
6. Icon page shows an explicit message in LiveContainer hosts (can defer to v3.2 if device testing slips; document in release notes).
7. Version numbers bumped only after P0–P2 checklist review; no premature release publish.
